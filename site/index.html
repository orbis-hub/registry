publish a module
  1. start from the module template, build your thing, push it to github.
  2. tag a release v0.1.0. the template's workflow attaches module.tgz to it.
  3. fill in the form. it writes the registry entry for you and opens a prefilled submission on github. a bot checks the tarball and turns it into a pull request; once merged, every hub sees your module in the store within the hour.
